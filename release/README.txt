MISTY PACKLAND
A tiny dark fantasy idle game that lives in a window on your desktop.
Version: see the main menu (bottom of the panel).

== English ==

Getting started
  Run MistyPackland.exe. The game is a small window: keep it open while you work.
  Day plants grow while you use your computer. Night plants grow in the dark, even when the game is closed.
  Lamps, powered by Ember earned from your work, light the island at night.

Controls
  Left click   - plant, harvest, open the seed wheel, buy
  Right click  - action ring (shop, book, options, mini mode, menu)
  Right drag   - move the view into the mist
  Ctrl + wheel - window size
  The Options tab in the Book has: borderless window, always on top, screen corner, transparent window,
  start with Windows, Windows notifications, interface size, smoothness.

Saves
  %USERPROFILE%\AppData\LocalLow\Eziek\Misty Packland\save_1.json ... save_3.json
  Back up this folder to keep your islands.

Uninstall
  Turn off "Start with Windows" in Options (or remove the "Misty Packland" entry in Task Manager > Startup apps),
  then delete the game folder and the saves folder above.

Privacy
  The game works fully offline and sends nothing anywhere. See PRIVACY.txt.

== Polski ==

Start
  Uruchom MistyPackland.exe. Gra to małe okno: zostaw je otwarte, kiedy pracujesz.
  Rośliny dnia rosną, gdy używasz komputera. Rośliny nocy rosną w ciemności, także przy zamkniętej grze.
  Lampy zasilane Żarem (energią z pracy) oświetlają wyspę w nocy.

Sterowanie
  Lewy przycisk  - sadzenie, zbiór, koło nasion, zakupy
  Prawy przycisk - pierścień akcji (sklep, księga, opcje, mini-tryb, menu)
  Przeciąganie prawym - przesuwanie widoku w głąb mgły
  Ctrl + kółko   - rozmiar okna
  W Księdze, w zakładce Opcje: okno bez ramki, zawsze na wierzchu, róg ekranu, przezroczyste okno,
  start z Windows, powiadomienia Windows, rozmiar interfejsu, płynność.

Zapisy
  %USERPROFILE%\AppData\LocalLow\Eziek\Misty Packland\save_1.json ... save_3.json
  Skopiuj ten folder, żeby mieć kopię zapasową wysp.

Odinstalowanie
  Wyłącz „Start z Windows” w Opcjach (albo usuń wpis „Misty Packland” w Menedżerze zadań > Aplikacje autostartu),
  potem usuń folder gry i folder zapisów podany wyżej.

Prywatność
  Gra działa w pełni offline i niczego nie wysyła. Szczegóły: PRIVACY.txt.
